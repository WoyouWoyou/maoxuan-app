# 阅读排版与朗读

采用第三版集中阅读面板，沿用纸色、朱红和宋体正文。

- 阅读区右上角「阅读选项」提供居中 / 平铺；默认居中，正文最大宽度 760px。平铺填满当前阅读区，始终单栏、正文左对齐。
- 设置页的「阅读与朗读」与阅读器共用偏好；自动写入 SQLite settings.readerPreferences，独立于模型配置。
- 朗读默认关闭。开启后提供全文朗读、悬停或键盘聚焦段落的「只读本段」「从这里读」。悬停不会自动发声。
- 全文从第一段开始；只读本段结束即停；从这里读持续至文末。正文注释编号不送入语音，问题提示和标注解释不朗读。
- 只允许一个阅读器持有播放器。切换文章、关闭朗读、更换服务/音色或卸载阅读器都会停止；切换段落取消旧请求，迟到音频不会播放。
- 当前段落高亮，可选跟随滚动。浮动控制在留白足够时靠近段落，窄布局时停靠右下；选项面板打开时让出面板位置。
- Edge 使用主进程 `@andresaya/edge-tts` 合成 MP3，Undici WebSocket 使用现有全局 dispatcher，遵守 HTTP/SOCKS 代理配置。renderer 仅通过受校验的 IPC 收取音频，不访问网络端点或磁盘路径。Blob 音频需要 CSP `media-src 'self' blob:`。
- 默认晓晓，另有云希、云健；速度 0.75 / 1 / 1.25 / 1.5 / 2 倍。Edge 音频速度即时调整；系统语音的速度在下一文本片段生效。
- 超长段落在句末或字符边界分块，每块最多 701 个 UTF-16 单位，不切断代理对。逐块播放，保留原段落编号。
- Edge 失败保留当前位置，提供重试和语音设置。系统语音使用 Web Speech API 的可用中文声音，缺少中文声音时明确提示切回 Edge。
- Edge 音频持久保存在应用 userData 下的 `speech-cache/v1`。按正文片段、音色、输出格式及合成参数生成 SHA-256 缓存键；请求 ID、文章 ID、播放倍速不影响复用。换回旧音色也可复用旧缓存。
- 全文朗读 / 从这里读在第一片段音频准备好后，启动单个后台工作器，按阅读顺序预生成其余片段。当前播放与后台预生成分开，不必等整篇准备好；暂停时后台继续，停止、切换文章/音色或关闭朗读则取消尚未完成的工作，已完成的磁盘缓存保留。
- 再次播放任何片段首先读取本地缓存，无需联网；主进程按缓存键合并同时到达的前台/后台请求，避免重复合成。取消单个请求不影响仍在使用同一音频的其他请求。
- 缓存文件包含版本标识及音频 SHA-256 校验，通过临时文件写入再原子重命名。损坏/不完整文件视为缓存未命中重新合成；失败或取消的生成不提交缓存。临时文件写入失败会明确报错。
- 播放器显示本次朗读范围内已缓存片段的数量。预生成失败不打断当前音频，轮到该片段时前台重试。缓存按需逐片读取，不把整本音频留在内存，也不通过预生成 IPC 传输大块音频。
- 切换和结束释放播放器 Blob URL；持久音频缓存继续保留。取消请求按窗口与请求 ID 区分，窗口销毁时中断网络。

Edge 是免密钥的社区接入，需要联网，正文发送至微软语音服务；不承诺服务持续可用。未启用时主进程拒绝合成。依赖及协议参考：<https://github.com/andresayac/edge-tts>。

验证包括排版与偏好持久化、IPC 无效参数、长段落 Unicode 切分、跨窗口取消隔离、过期取消与窗口销毁、重启后离线命中、音色/正文分离、共享生成与单消费者取消、缓存损坏恢复、后台串行预生成，以及真实在线合成。原生 Electron 窗口自动化连接超时，界面检查改用实际 ArticleReader 组件的独立浏览器预览；不等同于已验证原生系统语音兼容性。

## 核心五篇的安装包音频

内置音色固定为晓晓（`zh-CN-XiaoxiaoNeural`）；包含《实践论》《矛盾论》《论持久战》《反对本本主义》《中国革命战争的战略问题》的全部正文段落。

- 资源位于 `resources/core-audio/v1`，安装时复制到 `process.resourcesPath/core-audio/v1`。应用读取顺序为：内置音频 → 用户缓存 → 在线生成。内置音频只读使用，不复制到 userData。
- `manifest.json` 记录每篇文章、原始段落编号、片段键、音频字节数、SHA-256，以及整篇音频的时长。分段逻辑与阅读器使用相同的 `speechChunks`；原文预处理与内置书库导入相同，避免点击段落时匹配不到音频。
- `npm run audio:generate` 用 3 路并发逐片生成，失败自动重试，重新执行复用已完成的音频。可用 `-- --workers=1` 降低并发；需要代理时使用 `SPEECH_PROXY_URL` 环境变量。进度与失败列表写入 `.codegen/`。
- 全部生成后，额外导出五个可单独播放的完整 MP3 到 `output/core-five-audio/`。安装包仅包含去重片段与清单，不重复打包整篇 MP3。
- 生成脚本用 FFmpeg 完整解码每篇 MP3，验证音频可解码；该检查不等同于逐字人工校听。
- `npm run audio:check` 不调用线上服务，检查五篇当前正文与清单一一对应、每个片段都存在且哈希正确。macOS / Windows 的 electron-builder `beforePack` 钩子自动执行同一检查，缺失或过期音频会阻止打包。
- 更换其他音色时，缓存键自然不同，仍走在线生成与用户缓存；播放倍速调整继续复用晓晓原音频。
