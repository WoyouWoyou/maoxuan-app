## 首版的明确边界

- 文本提取阅读，不还原 EPUB 复杂排版/图片/公式；不支持 DRM、PDF/OCR。
- 关键词/FTS 加 AI 查询扩展，无 embedding；短书可直接覆盖正文，大书候选仍可能漏检。需要用实际书籍持续评估相关性。
- 每个书籍记录对应一个不可变正文版本；不同内容重新导入形成另一条书籍记录，同名可并存，不提供原地替换正文。
- 任务重启后不自动继续付费调用；用户显式继续索引，复用已完成块。任务执行上下文不是可自动复现的长期 Agent 记忆。
- 通用诊断保留旧字段形状作兼容，UI 与 prompt 已通用化；工作台与旧脚本的 sessions.update 仍保留，共用校验和事务。
- 费用不做硬编码估价或硬封顶；提供 Token 规模预估及实际/估算/未知用量。可为阅读、工作台和索引分别配置模型。
- 模型用量写入失败有内存重试队列，进程崩溃仍可能缺失；不把本地统计当服务商账单。
- 当前安装包未签名、未公证；未自动创建新版 GitHub Release。

## 0.3.1：恢复原书目录导航

书架沿用书籍已有的目录元数据：《毛选》保留核心五篇快捷入口和七卷分组，EPUB 根据解析得到的父级路径构建多层目录，保留书籍与篇章原有顺序。目录支持逐级展开、全部展开和全部收起，初始只展开第一个目录分支；TXT 的“正文”占位层不单独显示。搜索结果显示所属书籍与目录路径。

目录构建与展示分别封装在 renderer 的 library 功能内，只消费 ArticleMeta，不变更数据库、来源 ID 或阅读流程。新增 3 项目录构建回归测试；真实 Electron smoke 增加七卷、核心五篇、展开/收起、原文跳转及搜索位置验证。
