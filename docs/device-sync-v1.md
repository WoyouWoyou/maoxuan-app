# 局域网文本同步联调版（2026-11-02）

这是已实现的 Android ↔ 桌面手动文本同步子集；总体目标仍见 mobile-lan-sync-design.md。尚未完成完整同步方案或真机验收。

## 使用

1. 更新电脑应用和 Android 联调版，两端连接可互通的同一局域网。
2. 电脑「设置 → 设备同步 → 开启局域网同步」，复制配对码到手机。
3. 手机「我的 → 设备同步」粘贴配对码，点击「立即同步」。
4. 冲突会显示手机和电脑原文；选择后再次点击立即同步。若电脑在此期间又修改，会重新产生冲突。
5. 电脑关闭同步服务会使当前配对码失效。重启后需获取新码。电脑安装证书身份经系统安全存储加密保存，正常重启不会重建基线。

配对码等同本轮连接权限，只交给自己的手机。当前不记住配对凭据、不自动同步，不承诺后台运行；没有扫码、mDNS 或逐设备撤销界面。浏览器不支持自签名证书固定，必须使用新版 Android APK。网络隔离、VPN 选中了其他网卡或电脑防火墙可能阻止连接。

## 内容与边界

- 双向：内置毛选的阅读/工作台会话、版本、对话、会话内行动，独立待办，Markdown 记录及文件夹。
- 按稳定 ID 合并；笔记按条同步，整个阅读/工作台会话作为冲突边界。软删除状态传播，永久清空不传播墓碑（远端仍有内容时可能再次拉回）。
- 不同步：模型密钥、网络设置、附件笔记、导入书籍及其会话、朗读缓存、长征成长及收藏。带附件的笔记整体跳过，避免生成缺失附件。
- 只同步已保存内容，不传输编辑框内尚未保存的草稿。每轮文本上限 20 MB。
- 首次已有相同 ID 且内容不同，进入冲突，不用时间戳或本地版本号决定覆盖。各端本地 CAS 计数独立。
- 目前同步会发送全量文本清单；基础哈希用于识别修改与冲突，不代表已实现分页增量日志。
- 同步不是备份。手机写入记录与同步基线通过原子 batch 提交；桌面由 SQLite 事务提交。原有手机历史和电脑会话版本保留，冲突双方副本留在手机同步状态中。

## 传输

桌面仅在用户开启时监听一个私有 IPv4 地址上的 HTTPS 随机端口，只有受限 `/sync` POST 接口。每次开启生成 256 位随机认证凭据，配对码包含地址、协议及 SHA-256 证书指纹。Android 专用插件每次请求校验该确切证书及有效期，禁止 HTTP、公共地址、其他路径和重定向；不会全局关闭 TLS 校验。桌面恒定时间比对认证凭据，限制请求大小、连接数和超时。设备关闭时断开全部连接。

服务器证书使用 selfsigned 5.5.0 生成，私钥由 Electron safeStorage 加密保存；配对凭据只保留在当前进程/输入框内，不进入备份。开发测试的公共证书 fixture 不含私钥。

## 验证

- Electron + 真实 SQLite 与独立手机 IndexedDB：双向修改、不同笔记合并、重复同步、阅读历史/待办稳定身份、并发编辑、删除与编辑冲突、两种冲突选择、已提交但回执丢失后的重试、CAS 回滚。
- 实际 HTTPS 服务：拒绝无效凭据、拒绝错误协议、接受合法同步、关闭服务后拒绝旧连接。
- Android JVM 单测：只允许私网 HTTPS 同步端点；正确证书可通过，错误指纹/空证书链必须拒绝。由 GitHub Actions 随 APK 构建运行。
- 手机浏览器 8 条端到端流程及 17 项领域/存储测试，包括首页成就入口、真实成长记账与奖励去重。
- 尚需 Android 真机 ↔ 实际桌面应用的跨设备实测；浏览器、JVM 和独立数据库测试不能替代系统网络权限、防火墙、软键盘与挂起恢复测试。
