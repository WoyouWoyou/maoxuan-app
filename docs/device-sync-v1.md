# 局域网笔记与附件同步联调版（2026-11-03）

这是已实现的 Android ↔ 桌面手动笔记与附件同步子集；总体目标仍见 mobile-lan-sync-design.md。尚未完成完整同步方案或真机验收。

## 使用

1. 更新电脑应用和 Android 联调版，两端连接可互通的同一局域网。
2. 电脑「设置 → 设备同步 → 开启局域网同步」，复制配对码到手机。
3. 手机「我的 → 设备同步」粘贴配对码，点击「立即同步」。
4. 冲突自动保留电脑原记录，并生成可编辑的「同步冲突副本」保存手机修改；两份会同时出现在两端。请自行编辑、合并或删除，软件不自动覆盖任何一方。
5. 电脑关闭同步服务会使当前配对码失效。重启后需获取新码。电脑安装证书身份经系统安全存储加密保存，正常重启不会重建基线。

配对码等同本轮连接权限，只交给自己的手机。当前不记住配对凭据、不自动同步，不承诺后台运行；没有扫码、mDNS 或逐设备撤销界面。浏览器不支持自签名证书固定，必须使用新版 Android APK。网络隔离、VPN 选中了其他网卡或电脑防火墙可能阻止连接。

## 内容与边界

- 双向：内置毛选的阅读/工作台会话、版本、对话、会话内行动，独立待办，Markdown 记录及文件夹、笔记图片和录音。
- 按稳定 ID 合并；笔记按条同步，整个阅读/工作台会话作为冲突边界。软删除状态传播，永久清空不传播墓碑（远端仍有内容时可能再次拉回）。
- 不同步：模型密钥、网络设置、导入书籍及其会话、朗读缓存、长征成长及收藏。
- 附件先同步正文和清单，再按 384 KiB 分块传输，整文件 SHA-256 校验通过后才保存。单附件上限 100 MiB；中断会显示待重试，下一轮重新传输缺失文件，已成功附件不重复上传。源文件缺失会明确报错，不删除正文。大文件的内存及真机性能仍需实测。
- 只同步已保存内容，不传输编辑框内尚未保存的草稿。每轮文本上限 20 MB。
- 首次已有相同 ID 且内容不同，保留两份，不用时间戳或本地版本号决定覆盖。各端本地 CAS 计数独立。
- 目前同步会发送全量文本清单；基础哈希用于识别修改与冲突，不代表已实现分页增量日志。
- 同步期间，手机恢复备份入口禁用；恢复备份会清空活动同步基线，保留冲突副本，下一轮重新对账。同步不是备份。手机写入记录与同步基线通过原子 batch 提交；桌面由 SQLite 事务提交。原有手机历史和电脑会话版本保留，冲突原记录和副本同时保存在双方正常数据集中，手机额外保留本轮对照记录。

## 传输

桌面仅在用户开启时监听一个私有 IPv4 地址上的 HTTPS 随机端口，只有受限 `/sync` POST 接口。每次开启生成 256 位随机认证凭据，配对码包含地址、协议及 SHA-256 证书指纹。Android 专用插件每次请求校验该确切证书及有效期，禁止 HTTP、公共地址、其他路径和重定向；不会全局关闭 TLS 校验。桌面恒定时间比对认证凭据，限制请求大小、连接数和超时。设备关闭时断开全部连接。

服务器证书使用 selfsigned 5.5.0 生成，私钥由 Electron safeStorage 加密保存；配对凭据只保留在当前进程/输入框内，不进入备份。开发测试的公共证书 fixture 不含私钥。

## 验证

- Electron + 真实 SQLite 与独立手机 IndexedDB：双向修改、不同笔记合并、重复同步、阅读历史/待办稳定身份、并发编辑、删除与编辑冲突、冲突双副本保留及重试去重、已提交但回执丢失后的重试、CAS 回滚。
- 实际 HTTPS 服务：拒绝无效凭据、拒绝错误协议、接受合法同步、关闭服务后拒绝旧连接。
- Android JVM 单测：只允许私网 HTTPS 同步端点；正确证书可通过，错误指纹/空证书链必须拒绝。由 GitHub Actions 随 APK 构建运行。
- 手机浏览器 11 条端到端流程及 18 项领域/存储测试，包括首页成就入口、真实成长记账与奖励去重、图片/音频持久化显示播放、返回时保存笔记和关闭弹层。
- 独立数据库附件测试：双向正文和图片/录音、分块断线、重试完整性；实际字节校验一致。
- 尚需 Android 真机 ↔ 实际桌面应用的跨设备实测；浏览器、JVM 和独立数据库测试不能替代系统网络权限、防火墙、软键盘与挂起恢复测试。

## Android 返回与安装

原生 Back 回调接入统一返回流程：优先关闭对话框、抽屉及临时面板；笔记编辑先保存再回列表；阅读页回实践、成就详情回上一级，其他主标签回首页；仅首页退到后台。录音中暂时阻止退出并提示先结束录音。系统边缘手势/键盘优先级仍需真机验收。

0.2.1 APK 包名 `com.liamreed.maoxuan.mobile.preview.stable`，名称「毛选·随身版」，使用仓库 Actions 加密密钥中的固定 PKCS12 签名。旧临时调试签名无法复用，因此新旧应用并行，旧数据不删除；可先将旧手机已保存内容同步到新版桌面，再由新手机包拉取。未来该包名的 Actions 构建可覆盖升级。两端均需更新才能使用附件协议。
